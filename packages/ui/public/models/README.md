# 3D-модели форсунок, прожекторов и чаш

## Что в поставке

Пятнадцать моделей: **тринадцать своих** и **две со Sketchfab** (о них — в
конце файла, там же атрибуция).

### Свои — процедурная генерация

Тринадцать моделей, собранных **процедурно в Blender 5.2** по каталожным
пропорциям архитектурных фонтанов (резьба 3/4" — Ø26 мм, шестигранник под ключ
32 мм, выходные отверстия 8–16 мм у струйных насадок и 30–50 мм у пенных,
кольцевые коллекторы 150–250 мм). Скрипты-построители лежат вне репозитория, в
рабочих файлах задачи; модели пересобираемы.

**Источник и лицензия у всех тринадцати одинаковые: собственная процедурная
генерация, поставляется в составе программы, использование свободное** —
никаких обязательств по атрибуции.

## Куда класть свои файлы

Папки две, программа смотрит в обе:

| Папка | Когда использовать |
|---|---|
| **`Документы\Fountain Studio\models`** | В установленном приложении. Рядом с `fountain.config.json` и проектом, доступна на запись, обновление программы её не трогает. **Это основной путь.** |
| `packages/ui/public/models` (эта папка) | Поставочный набор в исходниках. Попадает внутрь собранного приложения и там только на чтение. |

Файл с одинаковым именем в пользовательской папке перекрывает поставочный. При
работе через браузер по `localhost` пользовательская папка недоступна — видна
только эта.

## Как добавить свою

1. Положите `.glb` в папку. Имя — латиницей, без пробелов и вложенных папок.
2. Добавьте запись в `index.json` **той же папки**:

```json
{
  "models": [
    { "file": "my-nozzle.glb", "name": "Как назвать в списке", "for": "nozzle",
      "credit": "кто автор", "license": "какая лицензия" }
  ]
}
```

3. Обновите страницу — модель появится в свойствах элемента в списке «3D-модель».

## Как программа понимает, что это за модель

По полю **`for`**: `nozzle` — форсунка, `light` — прожектор, `bowl` — чаша.
Модель показывается только в списке своего вида. Если поле не указано или в нём
что-то непонятное, модель показывается во всех трёх списках — лучше предложить
лишнее, чем спрятать положенный файл. Из самого `.glb` вид не определяется
никак: это просто набор треугольников.

## Как модель ставится в сцену

* glTF — Y-вверх, сцена — Z-вверх: модель автоматически поворачивается на 90°.
* Размер приводится к габариту элемента **по наибольшей стороне**, дальше
  работает поле «Масштаб модели». Для широких моделей (кольцевая форсунка,
  тюльпан) наибольшая сторона — диаметр, а не высота: если хочется выше,
  поднимите масштаб.
* Модель садится на свой нижний край: точка привязки элемента — основание.
* Ось «вперёд» у форсунки и прожектора — **+Z модели после поворота**, то есть
  в исходном файле это +Y. Наклон и азимут применяются к ней.
* Материалы у каждого экземпляра свои — выделение красит только выбранный
  элемент.
* Не загрузилась — остаётся встроенная геометрия, в консоли предупреждение.

## Где брать чужие модели

Проверяйте лицензию каждой отдельно:

* Poly Haven — <https://polyhaven.com/models> (CC0, фонтанной арматуры нет)
* Sketchfab, подборка CC0 — <https://sketchfab.com/plaggy/collections/cc0-public-domain-free-models-c1af6539a9ee49f4b3d51fabd6c25a85>
* Sketchfab по тегу fountain — <https://sketchfab.com/tags/fountain> (лицензии смешанные)
* Meshy — <https://www.meshy.ai/tags/fountain>
* Free3D — <https://free3d.com/3d-models/fountain> (лицензии смешанные)

`.fbx`/`.obj` переводите в `.glb` (Blender: File → Export → glTF 2.0) — загрузчик
понимает только glTF.
