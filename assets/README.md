# Исходники изображений

Оригиналы картинок проекта (логотипы, фото для тумблера темы). В приложении
используются их копии из `packages/ui/public/` — оттуда Vite раздаёт файлы по
адресам вида `/FBEST_final.png`.

| Файл | Назначение |
|---|---|
| `FBEST_final.png` | логотип для тёмной темы (шапка + иконка вкладки) |
| `FBEST_final2.png` | логотип для светлой темы |
| `moon.jpg` | луна в тумблере темы (тёмный режим) |
| `sun.webp` | солнце в тумблере темы (светлый режим) |
| `logo.jpg` | старый вариант логотипа (не используется) |

Чтобы заменить картинку в приложении: положите новый файл сюда **и**
скопируйте его в `packages/ui/public/` с тем же именем.
