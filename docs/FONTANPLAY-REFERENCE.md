# FontanPlay — конспект возможностей (референс для нового приложения)

Источник: http://www.fontankrasnodar.ru/o_fontanPlay.htm (Musidora, ИП Богданов А.А.)
Это программа, которую пользователь применял раньше. Новое приложение должно покрыть весь этот функционал и превзойти его.

## Железо / протокол
- USB-DMX интерфейс собственного производства: FTDI FT245R + PIC18F452, выход EIA-485 (75176), гальваническая развязка (оптрон 6N137 + DC0505). Питание от USB.
- Драйверы FTDI D2XX (VID=0403, PID=6001). Адаптер = аппаратный ключ лицензии.
- DMX512 (стандарт 1990), выход в устройства с частотой ~30 кадров/сек из буфера DMX.
- 512 или 1536 DMX-каналов (заявлено до 512×8 = 4096).
- Передача DMX-данных по WiFi через отдельные Server/Client утилиты.

## Структура данных
- **Шоу (Play List)** → отдельные файлы-программы → **32 секвенсора** (параллельно, до 256 в старших версиях) → секвенсор делится на **паттерны** длиной 1–255 → паттерн состоит из **сцен** (до 256 на секвенсор), каждая со своим временем выполнения, циклическое воспроизведение (loop).
- **Приоритет**: секвенсор с бóльшим номером перекрывает младший. Загрузка в DMX-буфер импульсная: значение держится, пока не придёт новая команда. В конце трека всё гасится (подготовка к следующей композиции).

## Секвенсор (окно)
- Закладка «Описание» — текстовые заметки, сохраняются с секвенсором.
- Закладка «Скрепка с DMX» — выбор каналов DMX, участвующих в секвенсоре (аналог библиотеки приборов).
- Закладка «Поле RGB» — ячейка = прожектор (3 канала), по вертикали каналы, по горизонтали сцены; редактирование цвета сразу в 3 каналах.
- Закладка «Поле каналов» — уровень каждого канала в сцене как яркость (0=чёрный, 255=белый).
- Правая панель: выбор секвенсора, возврат на сцену 1, режимы (выключен / статический / движение по сценам между двумя маркерами), указатель текущей сцены.
- Сохранение/слияние отдельных секвенсоров на диске (merge в блок секвенций).
- Колесо мыши: адреса DMX; +Shift — сцены; +Ctrl — секвенсоры; +Alt — таймер (Job Tempo).

## Окно «Звуковой файл»
- Загрузка музыкального файла (с вопросом «стереть треки?»).
- Громкость на каждую песню (выравнивание в плейлисте, рекомендация ~30%).
- «Частота дискретизации» при записи — облегчает попадание в доли ритма.
- «Окно всегда в фокусе» при записи; «Регенерация» — снижение FPS при слабом ПК (FPS-индикатор, норма ≥25).
- Огибающая волны; жёлтый указатель позиции, красная полоса — точка перехода по клику, сиреневый маркер (правый клик) — точка старта (Пробел / сиреневый «пуск»).
- Дорожки НЕ сохраняются автоматически — отдельная кнопка сохранения.

## Дорожки (треки)
- До 32 (в старших версиях до 256) параллельных независимых треков с жёсткой синхронизацией с музыкой, привязка к фреймам аудиофайла.
- Дискретность 50 мс; **трековое опережение до 5 сек** — компенсация инерции воды (задержки давления).
- Гистограмма заполнения дорожек; режимы отображения: одна дорожка / все / поле плотности.
- Запись «как игра» во время звучания музыки:
  - с клавиатуры (кнопки = сцены/секвенции, закладка «Клавиатура»),
  - мышью (движение вверх/вниз = абсолютный уровень 0–255 в треке),
  - прямой ввод с нескольких сцен секвенсора сразу (движение мыши влево-вправо),
  - импульсная запись: сцена держится заданное время (кратно 50 мс), иначе — до следующей сцены.
- Событие трека = {номер секвенсора, номер сцены, тип воздействия: стоп / пуск со сцены / прямая пересылка сцены}.
- Смещение всей дорожки на N мс; удаление дорожки; вкл/выкл дорожек на лету (отлов багов); групповые операции; замена сцены/секвенсора во всей дорожке; быстрые кнопки-пресеты фейдера с сохранением позиций.

## Клавиатура
- Клавиша → {секвенсор, сцена, тип воздействия}. 26 кнопок × 7 оперативных наборов × 8 банков = 1456 привязок.
- Наведение на кнопку с данными — сразу вывод в DMX (превью на фонтане).
- Массовые операции: сменить режим/секвенсор во всех кнопках набора, копировать/вставить набор.

## Настройки DMX (окно)
- «Каналы DMX» — количество групп прожекторов, клапанов, частотных регуляторов (группа ≠ прибор: параллельные прожекторы = одна группа).
- «Мин/Макс» на каждый канал: для насосов мин = струя 10 мм, макс = максимальная высота (калибровка).
- Переназначение каналов DMX; управление одним логическим каналом нескольких DMX-каналов.
- «Macros» — 32 макроса, статические (снимок фейдеров) и динамические (запущенные паттерны, бегущий свет, смена водных картин). Запись правой кнопкой при Enable Record. Вызов вручную, из Schedule или PlayList.

## Play List
- Список файлов, +/−/Clear, drag-переупорядочивание, двойной клик — запуск.
- Режимы конца трека: остановиться / повторять трек в кольце / повторять весь плейлист в кольце.

## Расписание (Schedule)
- 32 строки; переходы между режимами (не вкл/выкл): OFF (всё в 0), PAUSE (стоп на текущей сцене, без звука, последние паттерны работают), AUX-INPUT (от входного сигнала), DINAM (динамика без звука), DANCE (плейлист с музыкой), MACRO(01–32).
- Строка: время, режим, день недели / день месяца / месяц (ANY = любой), имя (16 символов), имя файла шоу.
- Закладка Switch — время вкл/выкл подсветки, чекбокс Always.

## Прочее
- Генератор редактируемых автофигур (автоматическое создание динамических сцен).
- Спектроанализатор.
- Эффекты: Rate, Decay.
- Визуализация фонтана и каналов DMX; отдельный компонент F3D.exe (редактируются только струи) — для создания треков вдали от объекта.
- Утилита расчёта DMX-адресов на DIP-переключателях.
- ОС Windows XP/7/8/10. Portable, запуск через _pusk.bat.

## Слабые места (что улучшаем)
- Один USB-адаптер собственного протокола = привязка к железу, нет Art-Net/sACN/RDM.
- Устаревший UI (много модальных окон), ручное сохранение, нет undo.
- Нет полноценного таймлайна с огибающими (запись только «на лету»), нет вырезания фрагментов аудио.
- 3D-визуализация ограниченная, отдельным exe.
- ~30 FPS DMX без гарантии равномерности шага.
