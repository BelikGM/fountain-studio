# Полный план: собрать объект с нуля и проверить всю программу

Это маршрут «от нуля до про» для ОДНОГО человека за ОДНИМ компьютером, без
фонтана: всё, что здесь есть, проверяется на столе. Порядок не случайный —
каждый шаг опирается на предыдущий, и если что-то не сходится, беда почти
всегда в предыдущем шаге.

Как пользоваться: идти сверху вниз, после каждого пункта сверять «что должно
получиться». Если не сходится — не идти дальше, а разбираться: дальше станет
только запутаннее.

Отдельно отмечено:

- **[железо]** — проверяется только на объекте, на столе не получится;
- **[долго]** — нужно подождать (расписание, отчёты, резервные копии).

Подробные описания разделов — в `РУКОВОДСТВО.md` (оно же кнопка «?» в
программе). Установка на новый компьютер — в `УСТАНОВКА.md`.

## Часть 1. Первый запуск

### 1.0. Установщик

- Запустить `FountainStudio-Setup-*.exe`. **Что должно получиться:** все
  страницы тёмные, в цветах программы: приветствие с логотипом FBEST, выбор
  папки (поле и кнопки тёмные), ход установки (синяя полоса на тёмном),
  последняя страница с флажком «Запустить Fountain Studio» — его подпись
  видна. Заголовок окна тёмный. Страницы «для всех пользователей / только
  для меня» нет — программа ставится для текущего пользователя.
- «Удаление» (Параметры Windows → Приложения): страницы тоже тёмные; после
  удаления в «Автозагрузке» Windows нет записи Fountain Studio, а проекты в
  «Документах» на месте.

### 1.1. Программа запускается и видит движок

- Запустить программу. В шапке справа — зелёная точка «движок подключён».
- Внизу окна идут цифры: «такт 50 мс», «отклонение …», «кадров …» — они
  растут.
- Строка заголовка окна — тёмная, в цветах программы (не белая системная):
  слева меню «Файл · Правка · Вид · Воспроизведение · Справка», посередине
  имя проекта, справа точка связи, ключ лицензии, «?», тумблер темы и кнопки
  Windows «свернуть / развернуть / закрыть» того же цвета. Окно таскается за
  пустое место строки, двойной щелчок разворачивает. Светлая тема — строка и
  кнопки Windows светлые.
- Пройти по всем пяти меню: пункты работают («Вид → Мельче» — всё мельче,
  Ctrl+0 — обратно; «Справка → План проверки» открывает этот документ).
- Сузить окно (до ~900 px): меню сворачивается в одну кнопку, вкладки, которым
  не хватило места, — в «Ещё», открытая вкладка всегда видна; значок папки у
  кнопки проекта не вылезает из неё. Меньше 800 px окно не сжимается.
- «?» (или F1): в справке поле «Поиск по справке» в одну строку с «Закрыть».
  Набрать «отладка» — карточки находок: документ › раздел, кусок текста,
  слово подсвечено. Щелчок по карточке — переход к месту (оно вспыхивает),
  набранное остаётся; щелчок в поле — находки снова.

**Если не так:** красная точка и «нет связи с движком» — движок не поднялся.
Смотреть `УСТАНОВКА.md` п. 10.

### 1.2. Лицензия

- Значок ключа в шапке → видно тариф и срок.
- Без лицензии открывается экран приветствия с «ID компьютера» — его и надо
  прислать продавцу.

### 1.3. Первый объект

- Кнопка с именем проекта в шапке → «Новый проект», задать имя (например
  «Проверка»).
- **Что должно получиться:** в шапке новое имя, внизу пропала надпись «объект
  не открыт», на вкладках пусто — это чистый объект.

## Часть 2. Вселенные и приборы

### 2.1. Завести вселенную

«Настройки» → «Вселенные (DMX и RDM)» → «+ Вселенная» → выбрать протокол:

- **Art-Net** — вписать IP ноды (на столе можно `127.0.0.1`);
- **sACN** — адрес не нужен, идёт групповой рассылкой;
- **USB-DMX (ENTTEC PRO / Open DMX / FountanPlay)** — выбрать COM-порт из
  списка найденных. У FountanPlay без подключённых переходников в «Адресе»
  написано «авто» (списка нет — выбирать не из чего); «Выход на устройстве» —
  разъём DMX на коробке.

Имя вселенной — любое, с пробелами и цифрами («Вселенная А», «Вселенная 2»);
поле не очищается. Пока новая вселенная не добавлена, её строка жёлтая с
пометкой «новая · не добавлена», а кнопка под таблицей называется «Добавить
вселенную» (рядом — «Не добавлять»).

Нажать «Добавить вселенную». Строка на несколько секунд станет зелёной
«✔ добавлена». Поменять что-то у уже работающей вселенной (имя, выход) —
кнопки «Применить» / «Отменить правки», пометка «не применена», после
применения — «✔ применена».

**Что должно получиться:** строка «✔ Применено», внизу панели «USB-DMX на этом
компьютере» показывает состояние драйвера. Правки БЕЗ «Применить» не
действуют — про это есть жёлтая полоса на всех вкладках.

### 2.2. Приборы

«Оборудование»:

- «Добавить приборы» — тип, вселенная, количество, имя. Насосы, клапаны,
  светильники RGB — по нескольку штук.
- Или «Добавить несколько типов сразу» — заведёт сразу набор.
- «Добавить фигуру фонтана»: «Кольцо», форсунок 36, насосы 1, светильники
  «= 36» → «Создать фигуру». **Что должно получиться:** 37 новых приборов
  (насос и 36 RGB подряд после занятых адресов), в 3D контур «Кольцо (36)», у
  каждой форсунки тот же насос и свой светильник. Насосов 4 «частями» — на
  виде сверху четыре цвета обводки по дугам; 2 «чередуя» — через одну.
- Размеры фигуры: у кольца поле «Радиус, м» (радиус 3 → под видом сверху
  «Диаметр: 6 м»), у квадрата «Сторона», у прямоугольника «Длина» и «Ширина»,
  у треугольника галочка «равносторонний» и «Сторона» (сняли галочку — три
  поля: основание, правая, левая; стороны 5 / 1 / 1 — ошибка «Такого
  треугольника нет…», «Создать фигуру» не нажимается), у звезды «Ребро».
- Стрелки у поля «Радиус»: ▲ — 3,5, ещё ▲ — 4, ▼▼▼ — 2,5; набрать 3,2 и
  ▲ — 3,7. Шаг всегда одинаковый, вверх и вниз.
- Нумерация: Ф1 сверху (у квадрата и прямоугольника — верхний правый угол),
  Ф2 — правее, по часовой; «Нумерация: против часовой» — Ф2 левее.
- Клапаны: форсунок 10, клапанов 4 — «клапанов меньше, чем форсунок: у 6
  форсунок клапана не будет…», «Делить: равномерно / с Ф1 подряд»; клапанов
  10 — «у каждой форсунки свой клапан»; 12 — «клапанов больше… сверьтесь с
  таблицей».
- Вид сверху: обводка — насос, заливка — свет, квадратик снаружи — клапан,
  подписи Ф1 и Ф2; треугольник из 33 форсунок — кружки не налезают друг на
  друга, подписи Ф1 и Ф2 не слипаются.
- «Раздача и адреса — посмотреть и поправить»: в списках «насос 1 · адр. 11»,
  «свет 3 · адр. 22–24»; во второй таблице адрес «свет 1» → 300 — он там и
  встал, остальные раздались в обход, рядом «авто».
- Создать кольцо радиусом 3 из 10 форсунок, в 3D выбрать Ф1 — X 0, Y 3; Ф6 —
  X 0, Y −3.

**Что должно получиться:** таблица с адресами подряд, без красных
предупреждений; «Диапазон» у каждого прибора укладывается в 1–512.

Проверить заодно:

- поменять адрес прибора на занятый — адрес краснеет со словом «пересечение»;
- набрать адрес «109» в поле, где было «1», — курсор не уходит из поля, строка
  стоит на месте; вышли из поля — таблица пересортировалась;
- у прибора на адресе 1 набрать «51», когда другой прибор стоит на 51, — в
  своей строке «51–51 пересечение с «…»», а чужая строка НЕ краснеет; дописать
  «3» — «513–513 вне 1–512», чужих красных нет; Esc — адрес остался прежним;
  Enter или выход из поля — адрес меняется (513 → 512);
- «Удалить приборы…»: окно с выбором «Отмеченные галочками / Все насосы / Все
  клапаны / Все светильники / Приборы фигуры «…» / Все приборы проекта», с
  числом и тем, где эти приборы используются; «Удалить N приборов» — окно
  выбора сразу сменяется подтверждением (сверху, не под ним); «Отмена» —
  ничего не удалено, окон нет; «Удалить» — удалены разом; Ctrl+Z возвращает
  всех разом. Галочка в заголовке таблицы отмечает все приборы списка;
- поставить вселенную, которой нет, — номер краснеет с подсказкой;
- «⚙» у прибора — калибровка (рабочий диапазон), «ПЧ» у насоса — управление
  частотником по Modbus **[железо]**;
- «Перенумеровать адреса по видам» — адреса раскладываются подряд.

### 2.3. Ручная проверка приборов

«Отладка»:

- подвигать ползунки: значения меняются и держатся; ползунок идёт за мышью
  без рывков, в том числе при включённой «Волне»;
- «Всем приборам сразу»: цвет для всего света, ползунок для всех насосов,
  «Открыть/Закрыть» для всех клапанов;
- «Тест-генератор» → «Волна», область «Всё» → значения бегут; область «Свет»
  → двигается только свет, насосы стоят;
- «Выключен» → всё возвращается в 0.
- «Показать»: «Насосы» — только насосы, «Светильники» — только свет; подписи
  на ползунках чёткие и на залитых, и на пустых.
- Кнопки вселенных: «Вселенная:» один раз, на кнопках — номер («1») или
  номер с именем («2 · Северная чаша»); полное название — в подсказке. Имя
  «Вселенная» без номера на кнопке не повторяется. То же на «Диагностике».
- Полоса сверху (если есть) — «Скрыть»: пропадает и через 15 минут
  возвращается.

**Если ползунки падают в 0 сами:** вверху вкладки будет полоса с причиной —
всегда ОДНА. На столе это обычно «Кадры в линию не уходят» или «Работает
аварийное гашение» — там же кнопка «Режим отладки». **Что должно получиться:**
после нажатия полоса становится жёлтой «Режим отладки…», ползунки держат
значение; обновить страницу (F5) и перезапустить программу — режим
сохраняется; в «Настройках» → «Аварийное отключение» галочка «Режим отладки
на этом компьютере» стоит, а галочка «Аварийное отключение» у самого проекта — тоже.
  Там же три галочки «Гасить: насосы / клапаны / свет» и «Ждать, секунд».
Перед сдачей объекта выключить.

## Часть 3. Схема и картины

### 3.1. 3D-схема

«3D»:

- «+ Форсунка», «+ Прожектор», «+ Чаша» (встают в 0, 0, 0) либо «Расставить
  фигурой» (кольцо, квадрат, прямоугольник, треугольник, звезда; форсунки или
  прожекторы) — получится контур «Кольцо 1» и т. п., в списке слева он
  раскрывается стрелкой; поворот контура — в его свойствах справа. Поля
  размеров и «Нумерация» — те же, что на «Оборудовании»; над ними две короткие
  подсказки: «Без приборов: …» и ссылка «Быстрее сразу с адресами: «Добавить
  фигуру фонтана»»;
- два кольца (36 и 12 форсунок): выбрать второй контур — в «Составе» сверху
  «В контуре (12)» с его форсунками, ниже «Остальные»;
- «Удалить контур…» → окно: «Только контур» / «Контур вместе с элементами» и
  галочка «и их приборы на «Оборудовании»». С элементами и приборами — со схемы
  ушли 12 форсунок, с «Оборудования» — их приборы, общий с другим кольцом
  прибор остался; Ctrl+Z вернул всё;
- боковые колонки: потянуть край левой — сужается, шире обычного не тянется,
  двойной щелчок — обычная ширина; кнопка со стрелками посередине края правой
  колонки — сворачивает её в полоску «Свойства», щелчок по полоске —
  разворачивает; после перезапуска ширина та же. На окне уже 1000 px правая
  колонка открывается свёрнутой;
- перетаскиванием расставить по геометрии объекта; у выбранного элемента
  справа — привязка к приборам (насос, клапан, свет);
- для квадратного объекта удобно «Сетка».

**Что должно получиться:** в 3D видно чашу и форсунки; когда на «Отладке»
поднимаешь насос — в 3D растёт струя того же прибора. То же можно прямо в 3D:
панель «Проверка приборов» справа внизу или ползунки выбранной форсунки.

- Облететь камерой струю вокруг: вода над зеркалом одинаково яркая со всех
  сторон, под зеркало не уходит; утопленное сопло видно под водой, струя
  начинается от поверхности.
- Моторная форсунка на 60–90 °/с: у основания плотный шнур капель, без
  отдельной «трубы», которая расходилась бы с брызгами.
- Глазик у строки в списке слева — элемент пропадает из 3D (с водой);
  глазик у раздела — весь раздел. Перезапуск программы — скрытое остаётся
  скрытым, на шоу и приборы не влияет.
- Чаша: «Z (дно)», «Высота борта», «Толщина борта» (растёт внутрь),
  «Облицовка борта» — образец камня, свой цвет или картинка из файла;
  «Зеркало воды» → «Уровень воды от дна»; «Перелив через борт» — вода
  вровень с кромкой, бугорок, плёнка по стенке без зазора. Выбрать готовую
  3D-модель чаши (в т. ч. двухъярусную) — вода и перелив ложатся по её форме.

### 3.2. Сцены

«Сцены» → «+ Сцена» → выставить значения приборов → «Включить на приборах».

- Сделать: «Всё на полную», «Тишина», «Половина», «Дежурный свет».
- «⚡ Генератор» — заготовки сразу пачкой.

**Что должно получиться:** включение сцены видно в 3D и на «Отладке»;
в списке слева у играющей сцены значок «играет».

### 3.3. Секвенсоры

«Секвенсоры» → «+ Секвенсор» → добавить шаги-сцены, задать удержание и фейд →
«Пуск».

**Что должно получиться:** картина меняется по кругу; на «Отладке» видно, как
идут значения; «Стоп всё» останавливает.

## Часть 4. Шоу под музыку

### 4.1. Загрузить трек

«Шоу» → «+ Шоу» → «♪ Загрузить аудио…».

**Форматы:** mp3, wav, ogg, m4a, flac — всё, что умеет браузер. Файл
КОПИРУЕТСЯ в папку объекта (`audio/`), поэтому потом его можно не искать:
объект самодостаточен, а перенос одним файлом (`Настройки` → «Перенос объекта
одним файлом») везёт музыку с собой.

### 4.2. Автопостановка

Нажать «⚡ Автопостановка».

**Что должно получиться:** две дорожки — «Вода — фигуры по долям» и «Свет —
цвет по частям», в объекте появились сцены с «⚡» в имени, а под кнопкой —
отчёт: сколько картин и смен цвета, темп, сколько частей, на сколько раньше
доли ставится команда, и самооценка («в сетку попало N %», «картина держится
N доли»). Замечания, если есть, там же.

Дальше править руками: двигать блоки, менять сцены, растягивать. Это черновик,
а не готовый номер (подробнее — `АВТОПОСТАНОВКА.md`).

### 4.3. Ручная работа на таймлайне

- «+ Дорожка блоков» → перетащить сцену на дорожку, растянуть, задать фейды;
- «+ Огибающая» → нарисовать кривую канала мышью;
- «⏺ Запись» — живая запись: жмёшь клавиши/сцены под музыку, они ложатся на
  таймлайн;
- вырезки монтажа: выделить кусок на звуковой дорожке → «Вырезать» (шоу
  становится короче, блоки подтягиваются);
- «Прилипание к долям» — блоки встают ровно в темп.

**Что должно получиться:** «Пуск» играет музыку и картину вместе; в 3D видно
то же, что будет на воде.

### 4.4. Плейлист

«Плейлисты» → «+ Плейлист» → добавить шоу, задать паузы между ними, режим
(один раз / по кругу), «начинать с начала» или «с места остановки».

**Что должно получиться:** «Пуск» играет шоу подряд; «Стоп» останавливает;
при повторном запуске «с места остановки» продолжает с того же пункта — даже
после перезапуска программы.

## Часть 5. Автопилот

### 5.1. Расписание

«Расписание» → «+ Расписание» → «+ Запись»: время, дни недели, действие
(сцена, секвенсор, шоу, плейлист или «Стоп — погасить всё»), гашение перед
запуском.

Поставить запись на ближайшую минуту и дождаться. **[долго]**

**Что должно получиться:** в своё время запись срабатывает, прежнее
останавливается, внизу окна видно, что идёт; в журнале — строка о срабатывании.
«Стоп — погасить всё» гасит ВСЁ, включая сцену покоя и служебный свет.

Заодно проверить:

- две записи на одно время — время краснеет, сверху «⚠ Записи в одно и то же
  время», сработает первая;
- выключенное расписание не срабатывает;
- перезапустить программу посреди дня — включится то, что должно идти сейчас;
- перевести часы Windows вперёд через время записи — запись догонится сама,
  в журнале «часы ушли вперёд… догоняем расписание».

### 5.2. Сцена покоя и служебный свет

«Настройки»:

- «Сцена, когда ничего не играет» — что горит, когда не играет ни сцена, ни
  секвенсор, ни шоу (вместо полной темноты);
- «Служебное освещение» — включает выбранные приборы по времени суток
  (например подсветку периметра), независимо от шоу.

**Что должно получиться:** остановили всё — загорается сцена покоя; в заданное
время включается служебный свет и перекрывает шоу на своих приборах.

### 5.3. Автозапуск

«Настройки» → «Автозапуск» → «Запускать при старте Windows».

**Что должно получиться:** после перезагрузки программа поднимается сама,
значком у часов, без окна; фонтан играет по расписанию.

## Часть 7. Ветер, аварии, безопасность

### 7.1. Ветер без датчика

«Настройки» → «Ветер» → «Ручной ввод — проверка без датчика». На «Отладке»
появляется поле ветра: вписать 8 м/с.

**Что должно получиться:** сначала «⏳ ждём 10 с подряд», потом само
«⚠ струи ограничены до N %»; насосы приглушаются, свет не трогается; в 3D
струи ниже. Вписать 0 — через «Отпускать, с» ограничение снимается.

Датчик по Modbus (RS-485 или 0–10 В / 4–20 мА через модуль) — **[железо]**.

### 7.2. Аварийное отключение

«Настройки» → «Аварийное отключение» — включено, ждать 10 с.

**Что должно получиться:** если вывод перестал доставлять кадры, насосы и
клапаны уходят в 0, в журнале и в Telegram — авария. На столе это
срабатывает само (доставлять некуда), поэтому для проверки форсунок его
выключают кнопкой прямо на «Отладке».

### 7.3. Закрытие программы

Включить сцену и закрыть программу целиком.

**Что должно получиться:** перед закрытием движок шлёт безопасный кадр —
вода в 0. Приборы, которые держат последнее значение при пропаже питания
компьютера, программой не закрыть: это решается на объекте (`УСТАНОВКА.md`
п. 9). **[железо]**

## Часть 8. Несколько проектов и совместная работа

- Кнопка с именем проекта (значок папки) открывает «Проекты» поверх вкладки;
  закрыть — крестиком справа вверху или щелчком по любой вкладке (и по той,
  что была открыта). Пока «Проекты» открыты, ни одна вкладка не подсвечена.
- Кнопка с именем проекта → «Новый проект», «Недавние», «Сохранить как»,
  «Открыть папку». **Что должно получиться:** новый проект ПУСТОЙ — в
  «Оборудовании» «Приборы (0)», в 3D пусто, а не приборы прошлого проекта.
- Сделать правку (любую) при выключенном автосохранении — в шапке рядом с
  именем появится жёлтая кнопка-дискета. Нажать её или Ctrl+S — кнопка
  пропадёт. Шапка при этом влезает целиком на 1280, 1366, 1600 и 1920.
- «Настройки» → «Автосохранение проекта»: по умолчанию автосохранение включено,
  раз в секунду. Выключить автосохранение, сделать правку и переключиться на другой проект —
  спросит «Сохранить и открыть / Не сохранять / Отмена». Выключить
  автосохранение — правки ждут Ctrl+S; при закрытии программы всё равно
  записываются.
- Открыть проект во ВТОРОМ окне (или с другого компьютера): вверху появится
  «⚠ Проект открыт ещё в одном редакторе», а правка поверх чужой не примется.
- «Перенос проекта одним файлом» — экспорт и импорт со всей музыкой и
  настройками линий.

## Часть 9. Что остаётся на объект

Это нельзя проверить на столе, но нужно проверить обязательно:

1. вывод на реальный интерфейс (Art-Net нода, ENTTEC PRO, USB-DMX FountanPlay)
   и совпадение адресов с монтажом;
2. насосы по Modbus: частотники, обороты, аварии;
3. датчик ветра: шкала, пороги, поведение при порывах;
4. RDM: видит ли нода приборы, меняется ли адрес удалённо;
5. звук: колонки, громкость, тембр, задержка между звуком и водой;
6. поведение при пропаже питания компьютера (реле или таймаут DMX у приборов);
7. как всё это выглядит на воде — то, ради чего всё и делается.
