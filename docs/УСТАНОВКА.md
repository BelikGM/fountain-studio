# Установка Fountain Studio на новый компьютер

Памятка для того, кто ставит программу на компьютер объекта с нуля. Идти по
порядку: каждый шаг опирается на предыдущий. В конце — проверка, что всё
заработало.

Что понадобится: компьютер с Windows 10 или 11 (64 бит), доступ в интернет на
время установки (для драйверов и проигрывателя музыки), установщик программы и
файл лицензии от продавца.

---

## 1. Сам компьютер: чтобы фонтан работал без человека

Эти настройки — не про программу, а про Windows. Без них фонтан встанет после
первого же отключения света.

1. **Включение после пропадания питания.** В BIOS компьютера (клавиша Del или
   F2 при включении) найти пункт вроде «Restore on AC Power Loss» / «After
   Power Failure» и поставить **Power On**. Тогда компьютер включится сам, как
   только вернётся питание.
2. **Автоматический вход в Windows.** Иначе после включения Windows ждёт пароль,
   и программа не запустится.
   - Windows 11: «Параметры» → «Учётные записи» → «Варианты входа» → выключить
     «Для повышения безопасности разрешить вход Windows Hello…».
   - Затем Win+R → `netplwiz` → снять галочку «Требовать ввод имени
     пользователя и пароля» → ОК → ввести пароль этой учётной записи.
3. **Не засыпать.** «Параметры» → «Система» → «Питание» → «Переход в спящий
   режим» — **Никогда**. Экран гаснуть может, компьютер — нет.
4. **Обновления Windows не в часы работы фонтана.** «Параметры» → «Центр
   обновления Windows» → «Дополнительные параметры» → «Период активности» —
   поставить часы работы фонтана (например, 08:00–23:00), чтобы Windows не
   перезагружалась посреди программы.

## 2. Программа

1. Запустить установщик `FountainStudio-Setup-<версия>.exe` (его даёт
   продавец). Папку можно оставить предложенную.
2. Запустить Fountain Studio с рабочего стола. При первом запуске откроется
   экран с тарифами.
3. **Лицензия.** На этом экране — «ID этого компьютера» и кнопка «Копировать».
   Отправить ID продавцу (почта, Telegram, телефон — там же на экране) и
   сказать тариф. Продавец пришлёт файл лицензии. Загрузить его кнопкой «⬆ У
   меня уже есть файл лицензии — загрузить». Лицензия привязана к этому
   компьютеру: на другом она не заработает.

Объекты программа хранит в `Документы\Fountain Studio\Проекты` — по папке на
фонтан. Перенос объекта с другого компьютера — скопировать его папку сюда
(или «Настройки» → «Перенос объекта одним файлом» → «Импортировать из
файла…»).

## 3. Драйвер интерфейса DMX (FountanPlay, ENTTEC)

**Зачем:** интерфейс USB-DMX (коробка FountanPlay / Musidora USB1DMX,
USB2DMX, ENTTEC PRO, Open DMX) внутри работает на микросхеме FTDI, и Windows
нужен её драйвер.

1. Подключить интерфейс к USB. Windows 10/11 обычно ставит драйвер сама за
   минуту-две (нужен интернет).
2. Проверить: «Настройки» → «Вселенные DMX» → блок «USB-DMX на этом
   компьютере» → «Драйвер FTDI: ✔ установлен».
3. Если там красным «драйвера нет»: скачать с сайта FTDI
   (ftdichip.com → Drivers → **D2XX Drivers** → Windows, «setup executable»),
   установить, переподключить интерфейс, перезапустить программу.

Жёлтое «драйвер есть, интерфейс ни разу не подключали» — это нормально до
первого подключения коробки.

Если приборы идут по сети (Art-Net, sACN), драйвер не нужен — см. п. 6.

## 4. Проигрыватель музыки (ffmpeg)

**Зачем:** когда шоу запускает сам движок — по расписанию или из плейлиста, в
том числе с закрытым редактором, — музыку он отдаёт в колонки через маленький
бесплатный проигрыватель `ffplay` из набора **ffmpeg**. Без него плейлисты и
расписание отыграют воду и свет **в тишине**. (Пока редактор открыт и шоу
запущено с вкладки «Шоу», музыку играет сам редактор — там ffmpeg не нужен.)

Установка — один из двух способов:

- **Проще:** открыть «Командную строку» (Win+R → `cmd`) и выполнить
  `winget install Gyan.FFmpeg`. Потом перезапустить Fountain Studio.
- **Вручную:** скачать с gyan.dev (раздел «release builds» →
  `ffmpeg-release-essentials.zip`), распаковать в `C:\ffmpeg`, добавить
  `C:\ffmpeg\bin` в переменную Path («Параметры» → «Система» → «О системе» →
  «Дополнительные параметры системы» → «Переменные среды» → Path → «Создать»),
  перезапустить программу.

Проверить: «Настройки» → «Громкость и тембр музыки» → «✔ Проигрыватель найден
— звук будет».

## 5. Датчик ветра и частотники по Modbus (если есть)

**Зачем:** датчик ветра и частотники с управлением по Modbus подключаются к
компьютеру отдельно от DMX — через переходник USB ↔ RS-485 (второй
USB-порт). DMX идёт только от компьютера к приборам, показания по нему не
приходят.

1. Подключить переходник USB-RS485. Драйвер Windows 10/11 обычно ставит сама.
   Если нет — по микросхеме на переходнике (написано в описании товара):
   CH340 — драйвер «CH341SER» с сайта WCH (wch-ic.com); CP2102 — «CP210x VCP»
   с сайта Silicon Labs; FTDI — «VCP Drivers» с ftdichip.com.
2. Посмотреть номер порта: «Диспетчер устройств» → «Порты (COM и LPT)» →
   например, COM3.
3. Датчик с аналоговым выходом (0–10 В или 4–20 мА, например Musidora
   «Wind») компьютер напрямую не читает — между датчиком и переходником
   ставится модуль «аналог → Modbus RS-485».
4. «Настройки» → «Ветер» → «Откуда брать ветер» → «Датчик по Modbus», порт,
   «Выход датчика» и числа из паспорта. Должно появиться «✔ датчик на связи».

Если на объекте стоит блок Musidora «Wind» с ручками «Уровень» и «Эффект» —
он снижает струи сам, мимо компьютера. Не снижать дважды: либо в программе
«Не учитывать ветер», либо ручку «Эффект» на блоке — в крайнее левое
положение.

## 6. Сеть (если приборы по Art-Net или sACN)

1. Компьютер и Art-Net ноды — в одной сети. Компьютеру задать постоянный
   IP-адрес в той же подсети, что у нод (например, если нода 192.168.0.50 —
   компьютеру 192.168.0.10): «Параметры» → «Сеть» → адаптер → «Изменить
   назначение IP» → вручную.
2. При первом запуске Windows спросит, разрешить ли Fountain Studio доступ к
   сети, — **разрешить** (частная сеть). Иначе ноды не будут видны.
3. «Настройки» → «Вселенные DMX» → у вселенной протокол Art-Net и IP ноды →
   «Применить». Проверить: «Диагностика» → «Art-Net ноды» → «на связи».

Планшет с TouchOSC или умный дом (MQTT) — «Внешние пульты» → «Подключение».

## 7. Автозапуск

«Настройки» → «Автозапуск» → галочка «Запускать при старте Windows». Программа
будет запускаться при входе в Windows значком у часов, без окна, и держать
фонтан по расписанию. Вместе с п. 1 это даёт: пропал свет → вернулся →
компьютер включился → Windows вошла сама → программа запустилась → по
расписанию играет то, что должно идти сейчас.

Закрытие окна программы фонтан НЕ останавливает: программа остаётся значком
у часов. Остановить фонтан и выйти — правой кнопкой по значку → «Остановить
фонтан и выйти…».

## 8. Уведомления в Telegram (необязательно)

«Настройки» → «Уведомления в Telegram»: токен бота, чат, «Проверить связь».
Токен хранится на этом компьютере и в папку объекта не попадает.

## 9. Приборы на случай, если компьютер выключится

DMX-приёмники держат последнее принятое значение. Если у компьютера
пропадёт питание, программа не успеет погасить приборы — вода может остаться
на последней картине. Защита на стороне железа:

- у DMX-декодеров частотников и драйверов света — если в меню есть «при
  потере сигнала» (Signal Loss / No DMX) — выбрать **0 / Blackout**;
- если такой настройки нет — реле по питанию насосов, которое держится
  сигналом от компьютера (вопрос к электрику объекта).

Пока программа работает, она сама гасит воду при сбое связи с приборами
(«Настройки» → «Аварийное отключение») и шлёт безопасный кадр при выходе.

## 10. Резервная копия настроек — сразу после наладки

Когда всё настроено (лицензия, бот, вселенные), сделайте копию настроек самой
программы: «Настройки» → «Резервная копия настроек программы» → «Сохранить в
файл». В ней лицензия, токен Telegram-бота, настройки движка и список недавних
объектов — то, чего НЕТ в копии объекта. Держите файл не на том же диске
(флешка, облако, почта себе). В файле лежит токен бота — это пароль.

Восстановление на том же компьютере: та же панель → «Восстановить из файла…»
→ перезапустить программу. На ДРУГОМ компьютере лицензия не заработает — она
привязана к железу, её выпускают заново по «ID компьютера» (п. 2).

## 11. Проверка после установки

1. Программа открывается, внизу справа зелёная точка — «движок подключён».
2. «Настройки» → «Вселенные DMX»: драйвер FTDI ✔ (или Art-Net ноды на связи
   на «Диагностике»).
3. «Отладка»: подвинуть ползунок насоса — насос откликается.
4. «Настройки» → «Громкость и тембр музыки»: «✔ Проигрыватель найден».
5. Запустить плейлист, закрыть окно — музыка и вода продолжаются; значок у
   часов на месте.
6. Перезагрузить компьютер — без касания клавиатуры программа поднимается
   значком, по расписанию играет то, что должно.

Полный план проверки всех возможностей программы — `ПЛАН-ПРОВЕРКИ.md`.
