## Постановка шоу и 3D

- ✅ Новые типы форсунок: «вариативная» (струя раскрывается в конус и собирается)

- ✅ Копирование/вставка блоков на таймлайне, выделение рамкой, групповой сдвиг.
- ✅ Привязка к битам: сетка BPM из аудиоанализа, прилипание блоков к долям.
- ✅ Библиотека эффектов: радуга по кольцу, дыхание, каскад, салют, радиальная

- ✅ Сглаживание огибающих и прореживание точек, записанных вживую.
- ✅ Цветовые пресеты и палитры для RGB-сцен.

## Надёжность и эксплуатация

- ✅ **Несколько объектов на одном компьютере.** Объект — самодостаточная
  папка в «Документы\Fountain Studio\Проекты»: `project.json` (схема, сцены,
  шоу), `lines.json` (вселенные, протокол, выходы, тик), `audio\`, `logs\`,
  `backups\` и ярлык `<Имя>.fsproj`. Папку можно унести на флешке — у коллеги
  откроется то же самое. В самой программе остаются только недавние объекты,
  лицензия и токен Telegram (он специально не в папке объекта). Открыть можно
  четырьмя способами: экран «Проекты» при запуске (свежий под Enter), кнопка в
  шапке на ходу, двойной щелчок по `.fsproj`, аргумент `--project <папка>`
  (им же пользуется автозапуск). Переключение без перезапуска движка; идёт
  шоу — спросим. Есть создание, «Сохранить как…» (копия без журнала и
  бэкапов) и закрытие объекта. Прежний единственный проект при первом запуске
  новой версии копируется в новую раскладку. Вторая копия программы не
  поднимается: передаёт путь первой и закрывается. Самопроверка:
  `npm -w @fountain-studio/engine run projects-test`.

- ✅ Журнал событий в UI: что и когда запускалось, ошибки движка. **Пишется на
  диск** рядом с проектом (`logs/events-ГГГГ-ММ-ДД.jsonl`, по файлу на сутки,
  хранение 60 дней): переживает перезапуск, нумерация продолжается, битая
  строка после обрыва питания чтение не роняет. Самопроверка:
  `npm -w @fountain-studio/engine run eventlog-test`.
- ✅ **Аварийное отключение**: если такт встал или выход на линию не доставляет
  дольше заданного времени (по умолчанию 10 с), насосы и клапаны принудительно

  «Аварийное отключение»), состояние видно там же и уходит в журнал и Telegram.
  Самопроверка: `npm -w @fountain-studio/engine run failsafe-test`.
- ✅ Авто-бэкапы проекта с историей и восстановлением.
- ✅ Установка автозапуска при старте Windows из интерфейса.

## Продукт и продажа

- ✅ Режим «только запуск» (лицензия): урезанная сборка для заказчика, полный
  редактор открывается ключом.
- ✅ **Учёт и отзыв лицензий.** `issue-license.ts`: три срока (пробный 30 дней /
  год / бессрочно), имя компьютера отдельно от имени покупателя (`--device`,
  `rename` — один ID может сменить владельца или просто забыться, как назвали),
  `list` показывает всё разом: кому, какой ПК, срок, состояние, отозван ли.
  Отзыв (`revoke`/`unrevoke` + `export-revocations`) — не мгновенный (лицензия
  офлайновая, подпись саму по себе не отозвать), а через список ID, который
  движок подтягивает по сети сам, когда она есть (`app-config.json` →
  `license.revocationUrl`); без сети ничего не меняется — офлайн никогда не
  выглядит как отзыв. Разбор решения — `ARCHITECTURE.md` §28. Самопроверка:
  `npm -w @fountain-studio/engine run license-test`.
- ✅ Экспорт/импорт проекта одним файлом (проект + аудио + **настройки линий
  DMX**): перенесённый на другой компьютер объект больше не остаётся немым.
