# Идеи доработок и улучшений удобства

Рабочий список — кандидаты на следующие фазы. Порядок внутри разделов ≈ по
соотношению «польза / трудоёмкость». Пометки: ⚡ быстро (часы), 🔨 средне
(день-два), 🏗 крупно (неделя+).

## 1. Удобство оператора (UX)

- ⚡ **Кнопка «Пауза всего»** рядом с BLACKOUT: три режима вместо двух —
  аварийный стоп / пауза с удержанием текущей картины / продолжить.
  (Идея пользователя, 19.07.2026.)
- ⚡ **Подтверждение удаления** сцены/секвенсора/шоу/плейлиста — сейчас
  удаляются в один клик безвозвратно.
- 🔨 **Отмена/повтор (Ctrl+Z / Ctrl+Y)** для правок проекта — сейчас любая
  правка необратима. История последних N состояний проекта уже почти
  бесплатна: проект — один JSON.
- 🔨 **Мастер нового объекта**: диалог «светильников: 100 × RGBW, насосов: 50,
  клапанов: 50» → авто-создание приборов с адресацией по группам + авто-кольцо
  в 3D. Из нулевого проекта к рабочему патчу за минуту. (Идея пользователя.)
- ⚡ **Поиск/фильтр по имени** в списках приборов и сцен (на большом объекте
  сотни позиций).
- ⚡ **Кликабельная строка «воспроизведение»** в статус-баре — переход к тому,
  что сейчас играет.
- 🔨 **Режим оператора**: упрощённый экран с крупными кнопками (запуск
  плейлистов/сцен, стоп) — для дежурного персонала и планшета; переключение
  паролем.
- 🔨 **Перетаскивание (drag-and-drop)** для порядка сцен в секвенсоре, шоу в
  плейлисте, приборов в списках.
- 🔨 **Локализация** интерфейса (рус/англ) — задел на продажу за пределы РФ.

## 2. Постановка шоу (творческие инструменты)

- 🔨 **Новые типы форсунок** (запрос пользователя): «вариативная» — одна струя
  раскрывается в конус и собирается назад (угол распыла = отдельный DMX-канал
  или автоцикл); «моторная по окружности» — сопло физически едет по периметру
  круга с настраиваемой скоростью.
- 🔨 **Копирование/вставка блоков** на таймлайне (Ctrl+C/V), выделение
  нескольких блоков рамкой, групповой сдвиг.
- 🔨 **Привязка к битам**: сетка BPM из аудиоанализа на линейке таймлайна,
  прилипание блоков к долям.
- 🔨 **Библиотека готовых эффектов**: «радуга по кольцу», «дыхание», «каскад»,
  «салют» — параметризованные генераторы поверх геометрии 3D (расширение
  текущего «⚡ Генератора»).
- ⚡ **Сглаживание огибающих**: прореживание записанных вживую точек, плавные
  кривые между точками.
- 🔨 **Цветовые пресеты и палитры** для RGB-сцен; генератор «радуга по фигуре».
- 🏗 **Рендер шоу в видеофайл** (запись 3D-сцены в mp4) — показать заказчику
  программу до выезда на объект.
- ⚡ **Шаблоны шоу**: скопировать структуру дорожек существующего шоу под новый
  трек.

## 3. Надёжность и эксплуатация

- 🔨 **Журнал событий в UI**: что и когда запускалось (расписание, пульты,
  клавиши), ошибки движка — сейчас видно только в консоли процесса.
- 🔨 **Авто-бэкапы проекта** с историей (последние N версий + восстановление) —
  проект один JSON, стоит дёшево, спасает от «всё пропало».
- ⚡ **Установка автозапуска из интерфейса**: кнопка «Запускать при старте
  Windows» на вкладке «Настройки» (сейчас — PowerShell-скрипт руками).
- 🏗 **Уведомления об авариях**: ПЧ вернул код аварии, нода пропала с линии →
  push в Telegram / письмо / MQTT-топик. На объекте без дежурного это
  единственный способ узнать о проблеме вовремя.
- 🔨 **График джиттера и статистики** (искровая линия за последний час) вместо
  голых цифр в статус-баре.
- 🏗 **Резервирование движка**: основной/резервный ПК, автопереключение.

## 4. Железо и протоколы

- 🏗 **Датчик ветра → авто-снижение струй**: анемометр (Modbus/MQTT) и правило
  «ветер выше порога — высота струй ограничивается N%». Классическая
  фонтанная автоматика, сильный продающий аргумент.
- 🔨 **Телеметрия насосов по Modbus**: чтение тока/оборотов/температуры ПЧ
  (не только запись уставки) — панель здоровья насосов.
- 🔨 **Полный E1.20-опрос на реальном железе**: сенсоры RDM-приборов
  (температура прожектора и т.п.) — слой готов, ждёт железа.
- 🔨 **DMX-in как триггер**: внешний DMX-пульт запускает сцены/шоу (захват
  входящего Art-Net уже есть — осталось повесить на него действия).

## 5. Продукт и продажа

- 🏗 **Режим «только запуск» (лицензия)** — отложенная идея (см. память
  проекта): урезанная сборка для заказчика — запуск плейлистов/расписания без
  редактирования; полный редактор открывается лицензионным ключом. Основа
  монетизации: объект получает плеер, постановщик — студию.
- 🔨 **Экспорт/импорт проекта одним файлом** (архив: проект + аудио) — перенос
  между ПК и передача заказчику в один клик.
- 🔨 **Автообновления** настольного приложения (electron-updater + GitHub
  Releases).
- 🔨 **Встроенная справка**: руководство (docs/MANUAL.md) внутри приложения,
  вкладка «Справка» или кнопка «?».
- 🔨 **Тур при первом запуске**: подсказки поверх интерфейса по шагам
  «Приборы → Сцены → Шоу» для нового пользователя.
- ⚡ **Демо-проект из коробки**: готовое маленькое шоу с музыкой при первом
  запуске — покупатель сразу видит продукт в действии, а не пустой экран.

## Предлагаемый ближайший порядок

1. Подтверждения удаления + «Пауза всего» (⚡, безопасность повседневной работы).
2. Мастер нового объекта (🔨, главный ускоритель старта).
3. Ctrl+Z (🔨, самая частая боль редакторов).
4. Авто-бэкапы (🔨, страховка данных).
5. Новые форсунки (🔨, прямой запрос).
6. Режим «только запуск» (🏗, когда дойдёт до продажи).
