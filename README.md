# Fountain Studio

Приложение для управления светомузыкальными фонтанами: DMX512 / Art-Net / sACN / RDM,
таймлайн с музыкой, секвенсоры, расписание, 3D-визуализация. Современная замена FontanPlay.

Документация: [архитектура](docs/ARCHITECTURE.md) · [конспект FontanPlay](docs/FONTANPLAY-REFERENCE.md)

## Состояние: фаза 0

Работает: движок реального времени (тик 50 мс с компенсацией дрейфа), выходы Art-Net и sACN
на любое число вселенных, WebSocket API, консоль виртуальных фейдеров (512 адресов × N вселенных),
тестовые генераторы (синус/бегущая/пила по всем 1536 каналам), монитор равномерности потока.

Замер (Windows 11, Node 22, 3 вселенные × 512, тик 50 мс): интервалы кадров avg 50.00 мс,
σ 1.67 мс, ровно 20.0 Гц на вселенную; внутренний джиттер тика avg 0.61 мс, max 5.4 мс.

## Структура

```
packages/
├─ shared/   # общие типы: DMX, протокол сообщений UI↔движок
├─ engine/   # движок реального времени (чистый Node, работает и headless)
│  └─ src/tools/artnet-monitor.ts  # измеритель равномерности Art-Net потока
└─ ui/       # редактор (React + Vite)
docs/         # архитектура и справочные материалы
fountain.config.json  # конфигурация вселенных и выходов
```

## Запуск (разработка)

```bash
npm install
npm run dev          # движок (ws://localhost:9520) + UI (http://localhost:5173)
```

Отдельно:

```bash
npm run dev:engine   # только движок
npm run dev:ui       # только UI
npm run start:engine # движок без перезапуска при изменениях (эксплуатация)
npm run monitor      # слушать Art-Net на 6454 и мерить интервалы (Ctrl+C — отчёт)
npm run monitor -- --seconds 10   # замер на 10 секунд
```

## Конфигурация — `fountain.config.json`

```jsonc
{
  "server": { "port": 9520 },                    // порт WebSocket для UI
  "timing": {
    "tickMs": 50,       // шаг тика: 50 = 20 Гц (можно 25 = 40 Гц)
    "spinMs": 10,       // точная добивка тайминга (не менять без причины)
    "uiFrameMs": 100    // частота кадров в UI-визуализацию
  },
  "universes": [
    {
      "id": 1,
      "label": "Вселенная 1",
      "outputs": [
        // Art-Net: host = IP вашей ноды; universe с 0
        { "type": "artnet", "host": "192.168.0.50", "universe": 0 }
        // sACN: multicast по умолчанию; universe с 1
        // { "type": "sacn", "universe": 1, "priority": 100 }
        // У вселенной может быть несколько выходов одновременно.
      ]
    }
  ]
}
```

По умолчанию конфиг шлёт Art-Net на 127.0.0.1 — удобно для локальной проверки монитором.
Для реального железа замените `host` на IP Art-Net/sACN ноды.

## Требования

- Node.js ≥ 20, Windows 10/11 (кроссплатформенно, но целевая ОС — Windows)
- Art-Net/sACN нода для вывода DMX в линию (см. docs/ARCHITECTURE.md §4)
