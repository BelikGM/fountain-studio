# Fountain Studio

Приложение для управления светомузыкальными фонтанами: DMX512 / Art-Net / sACN / RDM,
таймлайн с музыкой, секвенсоры, расписание, 3D-визуализация. Современная замена FontanPlay.

Документация: [архитектура](docs/ARCHITECTURE.md) · [конспект FontanPlay](docs/FONTANPLAY-REFERENCE.md)

## Состояние: фаза 4 «3D»

Работает: движок реального времени (тик 50 мс с компенсацией дрейфа), выходы Art-Net и sACN
на любое число вселенных, WebSocket API, консоль виртуальных фейдеров, тест-генераторы —
и поверх этого редактор проекта:

- **Патч** — профили устройств (насос, клапан 0/255, свет 1-канальный, RGB, RGBW и свои
  с произвольными каналами), добавление пачками с авто-адресацией (поиск свободных блоков),
  контроль пересечений адресов и выхода за пределы 1–512;
- **Сцены** — статические картины с контролами по типу устройства (тумблер клапана, слайдеры,
  палитра для RGB), предпросмотр на реальном выходе, снятие значений с консоли;
- **Секвенсоры** — шаги «сцена + фейд + длительность», режимы «по кругу»/«один раз»,
  транспорт пуск/пауза/стоп, несколько секвенсоров одновременно (слияние HTP);
- **Шоу** — таймлайн с музыкой (mp3/wav через Web Audio): волновая форма, недеструктивные
  вырезки фрагментов (мышью или диапазоном с клавиатуры), переменное число дорожек — блоки
  сцен/секвенсоров с фейдами и огибающие каналов точками; у каждой дорожки опережение
  в мс (вода запускается раньше света) и mute; перемотка/скраб сразу отражаются на выходе
  DMX; пробел — пуск/пауза. Аудиофайлы движок хранит в `audio/` рядом с проектом;
- **Плейлисты** — последовательности шоу с паузами, «по кругу» или «один раз», переключение
  ⏮/⏭, движок играет их полностью автономно (звук — через ffplay из бесплатного ffmpeg;
  без него — вода и свет без музыки);
- **Расписание** — запуск плейлиста/шоу/секвенсора/сцены или общий стоп по системным часам ПК:
  время (можно с секундами), дни недели, включение/выключение записей;
- **Переадресация** — в патче: обмен адресами двух приборов (физически перепутаны),
  сдвиг адресов группы на ±N; сцены привязаны к устройствам и не ломаются;
- **Калибровка min/max** — рабочий диапазон каждого канала прибора (0 остаётся 0,
  1–255 растягиваются в min–max), применяется движком на выходе;
- **Страницы адресов** — режим «Адреса» в сценах: значения по адресам вселенной
  страницами по 32, как в FontanPlay;
- **Клавиши** — привязка запуска сцен/секвенсоров/шоу/плейлистов, «стоп всё» и BLACKOUT
  к клавишам (работают из любой вкладки);
- **3D** — схема фонтана: чаши (круглые/прямоугольные), форсунки девяти типов (прямая,
  веер, шатёр, цветок, вуаль, туман, пенная, ламинарная, вращающаяся) с координатами,
  наклоном и высотой струи, прожекторы; привязка к устройствам патча (насос/клапан/подсветка).
  Живая визуализация: частицы струй с баллистикой и инерцией давления (разгон/спад),
  клапан отсекает струю резко, цвет — от привязанного RGB-прожектора; данные — те же
  DMX-кадры, что уходят в железо, поэтому превью честное (шоу можно писать без объекта).
  Расстановка мышью, генератор кольца, массовая привязка «подряд», **импорт DXF** из
  AutoCAD (слои → форсунки/прожекторы/чаши, авто-масштаб по $INSUNITS; DWG предварительно
  сохраните как DXF);
- **Сеть** — мониторинг Art-Net нод (ArtPoll) и RDM-приборов на линиях (TOD): статус
  «жив/потерян», журнал появлений и пропаж — видно из тех. помещения, что прибор пропал
  с линии, не подходя к фонтану.

Сцены, секвенсоры, шоу и плейлисты исполняет движок — редактор можно закрыть, воспроизведение не прервётся.
Проект хранится в открытом JSON (`fountain.project.json`) и сохраняется автоматически.

Замер тайминга (Windows 11, Node 22, 3 вселенные × 512, тик 50 мс): интервалы кадров avg 50.00 мс,
σ 1.67 мс, ровно 20.0 Гц на вселенную; внутренний джиттер тика avg 0.61 мс, max 5.4 мс.

## Структура

```
packages/
├─ app/      # настольное приложение (Electron): окно редактора + запуск движка
├─ shared/   # общие типы: DMX, протокол сообщений UI↔движок
├─ engine/   # движок реального времени (чистый Node, работает и headless)
│  ├─ src/playback.ts              # воспроизведение: сцены, секвенсоры, шоу-таймлайн, HTP-слияние
│  ├─ src/project.ts               # хранилище fountain.project.json
│  ├─ src/audio.ts                 # хранилище аудиофайлов шоу (audio/ рядом с проектом)
│  └─ src/tools/
│     ├─ artnet-monitor.ts         # измеритель равномерности Art-Net потока
│     └─ playback-smoke.ts         # автотест воспроизведения (npm run smoke)
└─ ui/       # редактор (React + Vite): Консоль / Патч / 3D / Сцены / Секвенсоры / Шоу
   └─ src/three/FountainScene.ts   # Three.js-сцена: схема, частицы струй, свет
docs/         # архитектура и справочные материалы
fountain.config.json   # конфигурация вселенных и выходов
fountain.project.json  # данные проекта (создаётся движком, в git не попадает)
```

## Запуск (разработка)

```bash
npm install
npm run dev          # движок (ws://localhost:9520) + UI (http://localhost:5173)
```

Отдельно:

```bash
npm run dev:engine   # только движок
npm run dev:ui       # только UI
npm run start:engine # движок без перезапуска при изменениях (эксплуатация)
npm run monitor      # слушать Art-Net на 6454 и мерить интервалы (Ctrl+C — отчёт)
npm run monitor -- --seconds 10   # замер на 10 секунд
npm run smoke        # автотест воспроизведения: сцены, фейды, HTP, шоу, плейлисты, расписание
```

## Настольное приложение (Electron)

```bash
npm run app:dev    # разработка: движок + vite + окно Electron
npm run app:build  # собрать движок (engine.cjs) и UI в packages/app
npm run app:dist   # + инсталлятор Windows: packages/app/release/FountainStudio-Setup-*.exe
```

Приложение при старте ищет уже работающий движок на порту 9520 (например, службу
из «Автозапуска» ниже) и подключается к нему; если движка нет — поднимает свой
отдельным процессом и гасит его при закрытии окна. Данные (`fountain.config.json`,
`fountain.project.json`, `audio/`) живут в `Документы\Fountain Studio` — при первом
запуске создаётся конфиг по умолчанию (Art-Net на 127.0.0.1, 3 вселенных).

## Автозапуск (эксплуатация на объекте)

Движок работает без редактора; чтобы фонтан жил сам:

```bash
npm run engine:watchdog   # движок под сторожем: упал — перезапустится через 5 с
```

Автозапуск при входе в Windows (создаёт задачу планировщика `FountainStudioEngine`):

```powershell
powershell -ExecutionPolicy Bypass -File tools\install-autostart.ps1          # установить
powershell -ExecutionPolicy Bypass -File tools\install-autostart.ps1 -Remove  # удалить
```

Звук плейлистов в автономном режиме играет ffplay (часть бесплатного ffmpeg):
`winget install Gyan.FFmpeg`, при нестандартном пути — `audio.ffplayPath` в конфиге.
Редактор при этом не нужен; если ffplay не найден, шоу идут без музыки (вода и свет работают).

## Конфигурация — `fountain.config.json`

```jsonc
{
  "server": { "port": 9520 },                    // порт WebSocket для UI
  "timing": {
    "tickMs": 50,       // шаг тика: 50 = 20 Гц (можно 25 = 40 Гц)
    "spinMs": 10,       // точная добивка тайминга (не менять без причины)
    "uiFrameMs": 100    // частота кадров в UI-визуализацию
  },
  "universes": [
    {
      "id": 1,
      "label": "Вселенная 1",
      "outputs": [
        // Art-Net: host = IP вашей ноды; universe с 0
        { "type": "artnet", "host": "192.168.0.50", "universe": 0 }
        // sACN: multicast по умолчанию; universe с 1
        // { "type": "sacn", "universe": 1, "priority": 100 }
        // У вселенной может быть несколько выходов одновременно.
      ]
    }
  ]
}
```

По умолчанию конфиг шлёт Art-Net на 127.0.0.1 — удобно для локальной проверки монитором.
Для реального железа замените `host` на IP Art-Net/sACN ноды.

## Требования

- Node.js ≥ 20, Windows 10/11 (кроссплатформенно, но целевая ОС — Windows)
- Art-Net/sACN нода для вывода DMX в линию (см. docs/ARCHITECTURE.md §4)
